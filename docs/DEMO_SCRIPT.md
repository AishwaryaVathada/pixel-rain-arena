# Hackathon Demo Script

1. Open the GitHub Pages or local frontend and say: "This is Pixel Rain Arena, a static-first mock of a live arena architecture."
2. Touch and hold the canvas. The rain pauses immediately and the hit counter stops.
3. Release the canvas. The rain resumes and the counter starts moving again.
4. Show local-only mode. Explain that the frontend still works with no backend.
5. Start the backend and connect to `http://localhost:8000`.
6. Show live backend mode, latency, packets per minute, and connected clients.
7. Start Cloudflare Quick Tunnel or ngrok, paste the tunnel URL, and click Connect.
8. Scan the QR code from a phone and show the same live pause/reset state.
9. Close with: "The real engine can replace the mock backend later without changing the static frontend deployment story."
